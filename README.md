# Jev Ad Filter

Jev（TypeSafe AI の判定モデル）でページ要素が広告かどうかを判定し、広告を非表示にする Chrome 拡張機能です。

```
Chrome 拡張 (content.js → background.js) ──► localhost:8787 中継サーバー ──► api.typesafe.ai/v1/systemone
```

APIキーは中継サーバーだけが持ち、拡張機能には渡しません。

## セットアップ
1. `.env` に `jev.api_key=...` を書きます（すでに設定済み）。
2. サーバーを起動します（Node 18 以上、依存パッケージはありません）。
   ```
   cd server
   npm start
   ```
3. Chrome で `chrome://extensions` を開き、デベロッパーモードをオンにします。
   「パッケージ化されていない拡張機能を読み込む」で `extension/` フォルダを選びます。

## 仕組み
1. **候補の抽出**: 次の要素を候補にします。
   - iframe と AdSense の `ins`
   - id や class が広告っぽい要素（`ad`, `banner`, `sponsor`, `promo`, `pr` など）
   - 「広告」「PR」「スポンサー」というラベルを含むブロック
   - 既知の広告ドメインへのリンクを含む要素
2. **即時ブロック**: 既知の広告ドメインの iframe は、API を使わずにすぐ非表示にします。
3. **Jev による判定**: 候補の情報（タグ、class、テキスト、リンク先のホスト、サイズ）を `noul` 型の質問で判定します。確率がしきい値（既定 0.8）以上なら非表示にします。
4. 動的に挿入される広告も MutationObserver で拾います。サーバーは同じ内容の判定結果をキャッシュします。

## ポップアップ
- 非表示にした件数
- 拡張機能の ON/OFF
- サイト単位での無効化
- しきい値の調整
- サーバーへの接続状態

## デバッグ
- ページの DevTools コンソール（Verbose レベル）に `[Jev]` ログが出ます。
- サーバーのコンソールに判定ごとのリクエスト ID と確率が出ます。
- 非表示にした要素には `data-jev-hidden="jev"`（Jev の判定）または `"domain"`（ドメインで即ブロック）が付きます。
